
# 第四部分 思考题（伪代码 + 综合）

> 风格说明：和简答题区别不大，但更灵活，可能出现"模块拼接"题（如把决策树伪代码和随机森林框架拼在一起）。伪代码细节不必深究，大意正确即可。对教材内的内容，即使是冷门考点也要有印象。

**思考 4.1 ★（去年原题）写出随机森林的伪代码；提升集成学习中个体学习器多样性有哪些方法？详细说明随机森林中运用了哪些方法来提升个体学习器多样性。**

**答**：

```text
输入：训练集 D = {(x1,y1), ..., (xm,ym)}
      决策树数量 T
      每次划分时随机选择的特征数 k
输出：随机森林模型 H(x)

for t = 1, 2, ..., T:
    Dt ← 对 D 进行自助采样（有放回地随机采 m 个样本）
    ht ← TrainDecisionTree(Dt, k)
        # 训练决策树：在每个结点划分时，
        # 先从全部 d 个属性中随机选择 k 个属性（常取 k = log2 d），
        # 再从这 k 个属性中选择最优划分属性进行划分，递归生成树（通常不剪枝）
end for

输出 H(x)：
    分类：H(x) = 对 h1(x), ..., hT(x) 投票取多数
    回归：H(x) = (1/T) Σ ht(x)
```

提升个体学习器多样性的方法：**数据样本扰动、输入特征（属性）扰动、输出表示扰动、算法参数扰动**。

随机森林运用了其中两种：
1. **数据样本扰动**：每棵树用自助采样得到的不同采样集训练，训练数据互有差异；
2. **输入特征扰动**：每个结点划分时只从随机选出的 k 个属性子集中选最优属性，引入了属性选择的随机性。
双重随机性使得基学习器（决策树）之间的差异度增加，最终集成的泛化性能通常优于只有样本扰动的普通 Bagging。

**思考 4.1 补充变式（随机决策树生成伪代码）若题目只要求写随机森林中“单棵随机决策树”的生成过程，应如何作答？**

**答**：

```text
函数 RandomTreeGenerate(D, A, k)：  # D 为当前样本集，A 为可用属性集，k 为随机候选属性数
    生成结点 node
    if D 中样本全属于同一类别:
        将 node 标记为该类别叶结点; return node
    if A 为空 或 当前样本无法继续划分:
        将 node 标记为 D 中样本最多的类别; return node

    从 A 中随机选择 k 个属性，得到候选属性子集 A'
    在 A' 中按信息增益 / 增益率 / 基尼指数选择最优划分属性 a*
    按 a* 的取值或最优切分点划分 D，得到若干子集
    对每个非空子集递归调用 RandomTreeGenerate
    对空子集建立叶结点，类别取当前结点中样本最多的类别
    return node
```

这道变式的核心不是把每一行写得和教材完全一样，而是写出两件事：**仍然是决策树递归生成**，但**每个结点划分前先随机抽取一部分属性**，再从这些属性里选最优划分。

**思考 4.2 ★ 写出决策树生成算法（如 ID3/C4.5 框架）的伪代码。**

**答**：

```text
函数 TreeGenerate(D, A)：   # D 训练集，A 属性集
    生成结点 node
    if D 中样本全属于同一类别 C:
        将 node 标记为 C 类叶结点; return
    if A 为空 或 D 中样本在 A 上取值全部相同:
        将 node 标记为叶结点，类别 = D 中样本数最多的类; return
    从 A 中选择最优划分属性 a*        # 依据信息增益 / 增益率 / 基尼指数
    for a* 的每一个取值 v:
        为 node 生成一个分支，Dv = D 中在 a* 上取值为 v 的样本子集
        if Dv 为空:
            将分支标记为叶结点，类别 = D 中样本数最多的类
        else:
            以 TreeGenerate(Dv, A \ {a*}) 为分支结点   # 连续属性可不剔除
    return node
```

**思考 4.3 写出 K-means 算法的伪代码。**

**答**：

```text
输入：样本集 D = {x1, ..., xm}；簇数 k
输出：簇划分 C = {C1, ..., Ck}

从 D 中随机选取 k 个样本作为初始均值向量 {μ1, ..., μk}
repeat:
    令 Ci = ∅ (1 ≤ i ≤ k)
    for j = 1, ..., m:
        计算样本 xj 与各均值向量 μi 的距离 dji = ||xj − μi||₂
        将 xj 划入距离最近的簇 Cλ
    for i = 1, ..., k:
        计算新的均值向量 μi' = (1/|Ci|) Σ_{x∈Ci} x
        if μi' ≠ μi: 更新 μi ← μi'
until 所有均值向量均不再更新（或达到最大迭代轮数）
```

**思考 4.4 写出 AdaBoost 算法的伪代码（大意正确即可）。**

**答**：

```text
输入：训练集 D；基学习算法 L；轮数 T
初始化样本分布 D1(i) = 1/m

for t = 1, ..., T:
    ht ← L(D, Dt)                      # 基于分布 Dt 训练基学习器
    εt ← ht 在分布 Dt 上的加权错误率
    if εt > 0.5: break
    αt ← (1/2) ln((1−εt)/εt)           # 基学习器权重
    更新分布：Dt+1(i) ∝ Dt(i) × exp(−αt yi ht(xi))
              # 分对的样本权重减小、分错的增大，再规范化
end for

输出：H(x) = sign( Σ_{t=1}^{T} αt ht(x) )
```

**思考 4.5 ★（评价指标综合题）给定某分类模型的分类结果，要求计算查全率、查准率并做出评价。**
某疾病筛查模型在 1000 人（其中 50 人真实患病）上的预测结果为：预测患病 100 人，其中真实患病 40 人。请计算查准率、查全率与 F1，并从应用场景角度评价该模型。

**答**：
- TP = 40，FP = 60，FN = 10。
- 查准率 P = 40/100 = 40%；查全率 R = 40/50 = 80%；
- F1 = 2 × 0.4 × 0.8/(0.4 + 0.8) ≈ 0.533。
- 评价：疾病筛查场景中漏诊（假反例）的代价远高于误报，应优先看查全率。该模型查全率 80%，能查出大部分患者，且把需要复查的人群从 1000 人缩小到 100 人，作为初筛工具是可用的；但查准率仅 40%，会带来较多误报复查成本，且仍漏掉 10 名患者，可考虑下调判别阈值进一步提升查全率，或结合代价敏感学习改进。

**思考 4.6（模块拼接：Bagging + kNN）仿照随机森林"框架 + 基学习器"的拼接方式，写出以决策树桩为基学习器的 Bagging 伪代码，并说明 Bagging 为什么更适合搭配决策树而不是 kNN 这类稳定学习器。**

**答**：

```text
输入：训练集 D；基学习器数 T
for t = 1, ..., T:
    Dt ← Bootstrap(D)        # 自助采样
    ht ← 训练基学习器(Dt)     # 如决策树桩 / 决策树
输出：H(x) = 投票{h1(x), ..., hT(x)}    # 回归则取平均
```

原因：Bagging 主要通过"平均"来降低方差，对训练数据扰动敏感的不稳定学习器（如不剪枝决策树、神经网络）从中受益最大；而 kNN 这类稳定学习器对样本扰动不敏感，不同采样集训练出的个体差异很小，多样性不足，集成几乎没有提升。

**思考 4.7（场景选择题）对以下场景，分别说明你会选择哪种学习算法并简述理由：
(1) 需要给出可解释的判断规则的银行贷款审批；(2) 特征间近似独立的垃圾邮件分类；(3) 无标签的用户分群；(4) 小样本、高维、需要最大化分类边界的二分类任务。**

**答**：
1. 决策树：模型是一组 if-then 规则，可解释性强，便于向客户和监管解释拒贷原因；
2. 朴素贝叶斯：属性条件独立性假设与场景契合，训练只需统计概率，简单高效，对文本类任务效果好；
3. 聚类（如 K-means / 层次聚类 / DBSCAN）：无监督学习，无需标签即可发现用户群体结构；
4. 支持向量机：最大化间隔带来好的泛化能力，配合核函数可处理高维与非线性，且决策只依赖少量支持向量，适合小样本。

**思考 4.8（过拟合综合题）你训练的神经网络在训练集上精度 99%、测试集上仅 70%。请判断发生了什么问题，分析可能原因，并分别从数据、模型、训练策略三个角度给出解决办法。**

**答**：训练精度远高于测试精度，是典型的过拟合：模型把训练样本自身的特点当成了一般规律。
可能原因：网络过于复杂（参数远多于样本）、训练数据太少或噪声大、训练轮数过多。
解决办法：
- 数据角度：增加训练数据；数据增强（对训练数据进行随机变换或增强操作）；清洗噪声标签；
- 模型角度：减小网络规模；正则化（损失函数中加权重惩罚项，等效于"消减"网络）；Dropout 随机丢弃神经元；
- 训练策略角度：早停（验证误差上升即停止）；交叉验证选择超参数；也可使用集成学习（如多个网络 Bagging）降低方差。

**思考 4.9（朴素贝叶斯应用题）用朴素贝叶斯做垃圾邮件分类：说明你需要从训练数据中统计哪些量、预测时如何计算，以及当某个词在垃圾邮件中从未出现过时会发生什么、如何解决。**

**答**：
- 训练（统计）：① 先验概率 P(垃圾)、P(正常)——两类邮件占比；② 每个词 wi 的类条件概率 P(wi|垃圾)、P(wi|正常)——各词在两类邮件中出现的频率。
- 预测：对新邮件 x = (w1, ..., wd)，比较 \( P(垃圾)\prod_i P(w_i|垃圾) \) 与 \( P(正常)\prod_i P(w_i|正常) \)，取大者（实际实现常取对数求和防止下溢）。
- 零概率问题：若某词从未在垃圾邮件中出现，P(wi|垃圾) = 0，连乘会把整个后验抹成 0，其他词提供的信息全部失效。解决：拉普拉斯修正，分子加 1、分母加属性可能取值数（词表大小），避免零概率。

**思考 4.10（综合：算法流程默写）任选 K-means、AGNES、kNN、BP 之一，不看书写出完整算法步骤，并指出该算法的 2 个优点和 2 个缺点。（以 AGNES 为例作答）**

**答**：AGNES 步骤：
1. 将每个样本初始化为一个簇；
2. 计算所有簇两两之间的距离（最小/最大/平均距离）；
3. 合并距离最近的两个簇；
4. 更新距离矩阵，重复 2–3，直到簇数达到预设值 k（或所有样本合为一簇形成聚类树）。
优点：① 可以得到不同层次/粒度的聚类结果（树状图），无需事先确定唯一的簇数；② 实现简单、过程直观，可发现非球形簇（取决于簇间距离定义）。
缺点：① 计算复杂度高（需反复计算簇间距离），不适合大规模数据；② 合并操作不可撤销，一旦早期合并错误无法纠正，对噪声和离群点较敏感。

**思考 4.11（半监督思想·拓展）什么是半监督学习？简述自学习（self-training）算法的流程。**

**答**：半监督学习让学习器不依赖外界交互、自动地利用大量未标记样本来辅助少量有标记样本进行学习。自学习算法流程：
1. 收集所有有标记和未标记的数据，先只用有标记数据训练第一个监督模型；
2. 用该模型预测未标记数据的类别；
3. 选择满足预定义标准的预测结果（例如预测概率 > 90%，或预测概率最高的前若干个），将这些"伪标签"样本与原有标记数据合并；
4. 用合并后的数据重新训练一个新的监督模型，再次预测并把新的高置信样本加入伪标记池；
5. 迭代上述步骤，直到没有满足标准的未标记样本，或达到指定最大迭代次数。

**思考 4.12（开放题）列举常见的"强方差（高方差）模型"，并说明判断依据。**

**答**：决策树（不剪枝）、MLP（多层感知机/神经网络）、高阶多项式回归、支持向量机（特别是选择高斯核时）、k 很小的 kNN。
判断依据：方差度量训练集变动导致的学习性能变化。这些模型拟合能力强、灵活度高，对训练数据的小扰动非常敏感——数据稍变，学到的模型就明显不同，容易把训练集的偶然特性学进去（过拟合）。因此它们通常需要配合剪枝、正则化、早停或 Bagging 类集成来控制方差。

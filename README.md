# 重庆大学计算机类课程学习资料 | CQU Computer Science Study Resources

这里整理了重庆大学（CQU）计算机类课程的学习笔记、复习资料、实验代码和部分数据集，方便同学查阅、下载和交流。内容主要面向计算机科学与技术、软件工程、人工智能及相关专业的学生，也适合学习相应课程的其他同学参考。

## 课程目录

| 课程 | 目录 | 现有内容 |
| --- | --- | --- |

| 数据结构 | [Data_Structure](./Data_Structure/) | 数据结构上下篇 Markdown 笔记 |

| 数值计算与最优化算法 | [Numerical_Computation_and_Optimization_ Algorithms](./Numerical_Computation_and_Optimization_%20Algorithms/) | 课程 PDF、Python 实验代码及数据文件 |

资料按课程目录组织，各课程内容的完整程度不同，并可能随学习进度更新。笔记和实验结果仅供参考，如有错误欢迎指出。

## 获取和使用

在 GitHub 仓库页面点击 **Code → Download ZIP** 下载全部资料；也可以使用 Git 克隆到本地：

```bash
git clone https://github.com/Eviltro-Rium/CQU-Computer-Science-Learning-notes.git
```

Markdown 文件可直接在 GitHub 上阅读；PDF、演示文稿和实验报告可下载后使用相应软件打开。Python 实验的运行环境和依赖可能因实验而异，请先查看对应代码和数据路径。
